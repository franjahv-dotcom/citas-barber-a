# Interfaz de Mala Vida Barbers

Consulta las instrucciones completas en el README de la carpeta principal.

- `npm run dev`: interfaz en desarrollo; redirige `/api` a `127.0.0.1:3001`.
- `npm run build`: compila la interfaz para que el servidor la entregue.
- `npm run lint`: analiza el código.

Las direcciones de API son relativas al sitio; los clientes no necesitan acceder a un `localhost` distinto. Los horarios se muestran en la zona de la barbería.
